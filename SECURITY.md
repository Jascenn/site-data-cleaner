# Security Policy

## Supported versions

Only the latest tagged release is supported with security fixes.

## Reporting a vulnerability

Please do not report security issues in public GitHub issues.

- Use GitHub's "Report a vulnerability" in the Security tab, or
- Contact the maintainer through the repository owner profile.

Include a description, affected version, and minimal reproduction steps.

## Scope

- The extension runs entirely locally and makes no network requests.
- Reports involving the silent-list logic, F5 interception, or permission usage are especially welcome.
- Issues in the website or repository tooling are out of scope for security reports.

## Disclosure

We aim to acknowledge reports within a week and will publish fixes before detailed public disclosure.
